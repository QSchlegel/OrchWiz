# Fleet Ops Tracker Dashboard

Generated by `ops-tracker-export`.

### Fleet Daily Heatmap
```base
views:
  - type: heatmap-calendar
    name: Daily Activity
    filters:
      and:
        - file.inFolder("kb/fleet/ops-tracker/daily")
        - file.hasTag("ops-tracker/rollup")
    order:
      - note.rollupDate
    dateProperty: note.rollupDate
    trackProperty: note.totalPoints
    showDayLabels: true
    showYearLabels: true
    showLegend: true
    shape: rounded
    colorScheme: primary
    customColors: "#0f172a, #0ea5e9"
    viewMode: week-grid
    trackType: number

```

### Last-30-Day Ship Totals
```base
views:

    name: Daily Rows

        - file.inFolder("kb/ships")

    order:
      - note.rollupDate
      - note.totalPoints

      - file.name

```
